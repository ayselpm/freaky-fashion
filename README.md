# Freaky Fashion

Freaky Fashion är ett projektarbete byggt med Angular, Node.js, Express och SQLite.

## Starta backend

Öppna en terminal och kör:

```bash
cd backend
npm install
npm start
```

Backend körs på:

```text
http://localhost:3000
```

## Starta frontend

Öppna en ny terminal i projektets rotmapp och kör:

```bash
npm install
ng serve
```

Öppna sedan:

```text
http://localhost:4200
```

## Funktioner

- Startsida med hero, spots och produkter
- Produkter hämtas från SQLite-databasen
- Sökfunktion för produkter
- Produktsida med liknande produkter
- Varukorg och checkout
- Administration med produktlista
- Möjlighet att lägga till nya produkter
- Responsiv design
