
# Freaky Fashion

Freaky Fashion is an e-commerce web application developed as part of my Frontend Development studies.

The project includes a product catalogue, search functionality, shopping cart, checkout page and an administration interface for managing products.

## Technologies

- Angular
- TypeScript
- HTML & CSS
- Node.js & Express
- SQLite
- REST API

## Features

- Homepage with product listings and promotional sections
- Product details and similar products
- Product search
- Shopping cart and checkout page
- Admin interface with product overview
- Add new products
- Responsive design
- Product data retrieved from a SQLite database

## Getting Started

### Backend

```bash
cd backend
npm install
npm start
```

Backend: http://localhost:3000

### Frontend

Open another terminal in the project root:

```bash
npm install
npx ng serve
```

Frontend: http://localhost:4200
